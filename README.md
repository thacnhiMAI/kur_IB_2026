# Умная библиотека

Веб-приложение для поиска и чтения книг. Читатели могут сохранять избранное, получать персональные рекомендации и оставлять отзывы. Администраторы управляют каталогом, импортом, пользователями и модерацией.

[Открыть приложение](https://kur-ib-2026.vercel.app)

## Возможности

- Каталог с поиском, фильтрами, карточками и сведениями об источниках книг.
- PDF Reader с сохранением прогресса, поиском, выделениями и заметками. Выбранную область можно передать в AI Reader или открыть в поиске по фрагменту.
- AI Reader для объяснений, пересказов и вопросов. При включённой очереди задания может обрабатывать настольный Agent Studio или отдельный worker.
- Настольный 3D-просмотр и WebXR на совместимых устройствах. Для иммерсивного режима требуется HTTPS.

Стек: Next.js, React, TypeScript, Prisma и PostgreSQL.

## Локальный запуск

Нужны Node.js 24, npm и Docker с Compose. Запустите Docker, затем выполните:

```sh
npm ci
npm run setup
```

Откройте [localhost:3000](http://localhost:3000). Скрипт создаёт `.env` из шаблона, если файла ещё нет, запускает PostgreSQL, генерирует Prisma Client, применяет миграции, загружает демонстрационные данные и запускает Next.js. Для дальнейших запусков используйте `npm run db:up` и `npm run dev`.

### Переменные окружения

| Файл или среда | Назначение |
| --- | --- |
| [`.env.example`](.env.example) | Шаблон с примерами и перечнем настроек. |
| `.env` | Локальная БД, аутентификация, почта, параметры чтения и настройки Agent Studio. |
| Vercel Environment Variables | Настройки production для БД, авторизации, хранения файлов и подключённых провайдеров. |
| `.env.production.local` | Локальная копия настроек Vercel для ручной работы с production. Для обычного запуска и облачной сборки файл не требуется. |

Рабочие файлы окружения содержат секреты. Используйте для локальных проверок отдельную БД и тестовые учётные записи.

## Agent Studio

В Windows запустите настольное приложение командой `npm run agent:local`. Для обработки запросов сайта настройте `AGENT_WORKER_URL` и согласованный секрет `AGENT_WORKER_SECRET`. На сервере включите `READER_AGENT_QUEUE=1`. Для локального сайта запустите `npm run dev:agent` и `npm run agent:local-site` в разных терминалах. Отдельные фоновые обработчики запускаются командой `npm run agent:workers`.

Подробности о подключении, моделях, слотах и состоянии задач приведены в [руководстве Agent Studio](docs/agent-console.md).

## Проверки

```sh
npm run lint
npm test
npx playwright install chromium
npm run test:e2e
npm run build
```

Vitest запускает модульные и интеграционные тесты. Playwright проверяет браузерные сценарии и записывает результаты в `test-results/`. Команда `npm run test:agent-load` проверяет обработку очереди в отдельной схеме локального PostgreSQL с имитацией задержки модели.

## Развёртывание

В проекте Vercel production связан с веткой `main`. Команда сборки `npm run build:vercel` генерирует Prisma Client, применяет миграции и заполняет каталог в production, затем собирает Next.js. Установите переменные окружения в Vercel перед запуском сборки. Подробности приведены в [руководстве по развёртыванию](docs/operations/vercel-deploy-phase-e.md).
